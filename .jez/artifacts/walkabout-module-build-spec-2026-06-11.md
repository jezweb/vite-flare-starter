# Walkabout starter module — build spec

Promote the `walkabout` skill (guided voice tour + ask-the-app Guide + demo
recorders) into vite-flare-starter as a feature-flagged module. Every adopter so
far (FieldProof, HR Helper, RightCover) is a fork of this family — building it
here makes future forks flip a flag, and upgrades the canonical templates to
shadcn-native. The shipped sample tour IS the starter's own walkthrough.

Skill + deep reference:
- `~/.claude/skills/walkabout/SKILL.md` + `templates/` (FieldProof working files)
- `~/Documents/.jez/knowledge/guided-voice-tour-pattern.md` (rationale, gotchas, adopters)
- Public repo: github.com/jezweb/walkabout

## Starter integration points (verified 2026-06-11)

## Phases + gates

1. **Tour** — flag, halo CSS, shadcn Tour.tsx (+prefix-match), starter steps.ts,
   data-tour attrs on the 5 pages, generate audio, wire overlay. Gate: type-check +
   build; dogfood by wandering (chat self-redirect must NOT hang).
2. **Guide** — schema + migration, routes (composer role), starter knowledge.ts,
   Assist.tsx, QuestionsPage, nav entry. Gate: 3 live questions (covered / not-covered→defer / page-context).
3. **Recorders** — adapt the two .mjs for better-auth (storageState default; test-auth optional).
   Gate: frame-extract a recorded mp4.
